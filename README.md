# new-code-for-old-dos

Playground for writing code (using modern tools) that targets old DOS

## Introduction

This repository contains new code (newer than 2025) aimed at the old DOS
operating system. This is mostly a playground area for myself.

The idea is to use modern tools (Open Watcom on 64-bit Linux) to cross-compile
to 16-bit (or 32-bit) DOS.
